# QuickQR Studio 🚀

A modern, fast, and responsive web application built to generate high-resolution, custom QR codes instantly.

## 🌟 Features
- **Instant QR Generation:** Create QR codes for URLs, plain text, or contact information.
- **Custom Sizing:** Choose between Standard (150px), High-Res (220px), and Print-Ready (320px) resolutions.
- **Color Customization:** Personalize both code (foreground) and background colors.
- **Instant Download:** Export generated QR codes as clean `.png` images with a single click.
- **Client-Side Processing:** Fast and secure — no data is sent to external servers.
- **Fully Responsive UI:** Clean SaaS-inspired dashboard design that works seamlessly on mobile and desktop.

## 🛠️ Tech Stack
- **HTML5** — Semantic structure
- **CSS3** — Custom properties, CSS Grid/Flexbox, Plus Jakarta Sans typography
- **JavaScript (ES6+)** — DOM Manipulation & Event Handling
- **QRCode.js** — QR Code rendering engine
